# Neon Genesis VR

An open-world cyberpunk VR project targeting Meta Quest 3 and Quest 3S.

## Current prototype

- Three.js scene rendered in the browser
- WebXR entry button for compatible VR browsers
- First small neon city block
- Basic lighting, buildings, windows, and city atmosphere

## Run it

This project uses browser ES modules and needs to be served from a secure origin (HTTPS or localhost). Open `index.html` through a local development server or an HTTPS host.

On a Meta Quest 3 or 3S, open the hosted page in the Meta Quest Browser and choose **ENTER VR**.

## Built with

- Three.js
- WebXR
- JavaScript
